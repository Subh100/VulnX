# VulnX 🔐

Endpoint Monitoring & Anomaly Detection Prototype  
Built for AMD Slingshot Hackathon

---

## 🚀 Project Overview

VulnX is a cybersecurity-focused endpoint monitoring prototype designed to simulate system telemetry data and detect abnormal behavioral patterns using machine learning techniques.

The goal is to identify gradual attack patterns that traditional static monitoring systems may miss.

---

## 🎯 Problem Statement

Modern endpoints are increasingly targeted by stealthy, gradual attacks.  
Small abnormal changes in CPU usage, memory activity, process creation, and file access rates often go unnoticed until it is too late.

There is a need for intelligent monitoring systems that can detect behavioral anomalies in real time.

---

## 🧠 Proposed Solution

We simulate endpoint telemetry data and model gradual attack escalation patterns.

Our approach:
- Generate synthetic normal system behavior
- Simulate gradual attack progression
- Train an ML model to classify anomalies
- Visualize suspicious behavior via dashboard (planned)
